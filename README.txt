DIARIO FOREX — PROYECTO NETLIFY + PWA

1. Descomprime la carpeta calendario-forex.
2. Coloca tu logotipo a.jpg en la raíz, junto a index.html.
3. Sube la carpeta completa a un repositorio Git y conéctalo con Netlify.
4. Configura Netlify para instalar dependencias con npm install. No requiere comando de build; directorio de publicación: ".".
5. Activa Netlify Blobs en el sitio para guardar tokens y datos.
6. Publica con HTTPS.

La carpeta contiene la aplicación, manifiesto PWA, service worker, función de guardado y configuración de Netlify. Conserva el mismo sitio y almacenamiento Netlify al actualizar. Haz una copia de seguridad antes de sustituir archivos.

Instalación: Android/Chrome, menú > Instalar aplicación; iPhone/iPad, Safari > Compartir > Añadir a pantalla de inicio; PC, icono Instalar en Chrome/Edge cuando esté disponible.

El acceso sin conexión se limita a la interfaz previamente cargada. Guardar y sincronizar requiere conexión. Para compatibilidad PWA óptima, añade iconos PNG cuadrados de 192x192 y 512x512 además de tu logotipo JPEG.
